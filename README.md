Requiremnt
- php v8.3
- node v24.16.0
- mysql v9.7.0

Install apps

- git clone https://github.com/Fikkie007/rt.git
- cd backend
- composer install
- cd frontend
- npm install
- import backend\database\content.sql
- backend\database\structure.sql

Run dev server

- cd backed
- php artisan serve
- cd frontend
- npm run dev
